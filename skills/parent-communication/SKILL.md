# 학부모 소통

`early-childhood-education` 스킬의 `references/templates.md`(가정통신문·상담 양식)와 `policy.md`(건강·안전)를 기준으로 한다. `~/.claude/ece/user-notes.md`의 기관명·말투 규칙을 우선한다.

## 1. 공통 원칙
- **쉬운 말, 짧은 문장**. 전문 용어는 풀어 쓴다 ("누리과정 사회관계 영역" → "친구와 함께 지내는 경험").
- **핵심 먼저**: 날짜·시간·준비물·회신 기한을 맨 앞이나 표로 둔다.
- **존중하는 말투**: "~해 주시기 바랍니다", "~해 주시면 감사하겠습니다". 명령조·훈계조 금지.
- **다른 유아 정보 금지**: 다른 아이의 이름, 행동, 가정 사정을 쓰지 않는다.
- **약속하지 않기**: 기관이 확정하지 않은 일정·비용·조치는 단정하지 않고 사용자에게 확인을 요청한다.

## 2. 가정통신문
구성: 제목 → 인사 → 무엇을/왜/언제/어떻게 → 가정 협조 사항 → 마무리 → 기관장 명의 (→ 회신서).
- 한 장 이내.
- 행사 안내면 **목적**(유아가 무엇을 경험하는지)을 한 문장 넣는다.

## 3. 알림장 (개별 유아, 하루 기록)
- 3~6문장: 오늘의 놀이 일화 1개(구체적으로) + 일상(식사·낮잠·배변 — 영아반) + 가정 연계 한 줄.
- 매일 같은 문장 돌려쓰기 금지. 일화가 없으면 사용자에게 오늘 있었던 일을 묻는다.
- 예: "오늘 ○○이는 바깥놀이에서 개미 줄을 따라가며 '개미가 이사 가나 봐요!' 하고 친구들을 불렀어요. 함께 돋보기로 살펴보며 개미 다리를 세어 보았답니다. 댁에서도 산책할 때 작은 생명을 함께 찾아보시면 좋아할 것 같아요."

## 4. 민감한 연락 (사고·다툼·물림·감염병)
순서: **사실 → 즉시 조치 → 현재 상태 → 앞으로의 조치 → 사과/유감(해당 시) → 연락 창구**
- 사실만 쓰고 추측하지 않는다. 다른 유아는 "친구"로만 표현한다.
- 상처는 부위·정도·처치(예: 냉찜질, 연고)·병원 진료 권유 여부를 명확히 쓴다.
- 문자보다 **전화로 먼저 알리고** 문서를 남기라고 권한다.
- 감염병 안내는 질병관리청 지침과 기관 방침을 따르며, 등원 중지 기준은 사용자에게 확인한다.
- 아동학대가 의심되는 내용은 학부모 안내문 대상이 아니다. `policy.md`의 신고 절차를 안내한다.

## 5. 부모 상담
- **준비**: 유아별 일화 3~5개(강점 위주) + 부모에게 물어볼 질문 + 함께 지원할 제안.
- **화법**: 강점 → 구체적 사실 → 기관에서의 지원 → 가정에서 함께할 방법 → 부모 의견 경청.
- **어려운 주제**(또래 갈등, 발달 우려): 진단하지 않는다. "이런 모습이 관찰되어 함께 살펴보고 싶다" → 필요 시 영유아건강검진·전문기관 안내.
- **기록**: templates.md 부모 상담 기록 양식.

## 6. 예시 (작성 전에 형식과 말투를 맞추기 위해 읽는다)
- `examples/notice-field-trip.md`: 현장체험학습 가정통신문 + 회신서
- `examples/injury-notice.md`: 물림 사고 — 전화 순서, 문자 기록, 기관 내부 처리, 쓰지 않는 표현
- `examples/daily-notes.md`: 알림장 (만 1세 · 3세 · 5세)

말투 검토나 민감한 안내문은 `parent-communicator` 에이전트, 안전·건강 사항 확인은 `safety-health-advisor` 에이전트에 맡긴다.
