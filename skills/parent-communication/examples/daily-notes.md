# 예시: 알림장 (키즈노트 등) 3가지

> 가상 예시입니다. 원칙: 오늘의 구체적 일화 1개 + 배움의 의미를 쉬운 말로 + (영아는 일상) + 가정 연계 한 줄. 매일 같은 문장을 돌려쓰지 않습니다.

## 만 1세 (영아 — 일상 포함)
오늘 서아는 분유통 구멍에 공을 넣고 "쏙!" 하고 들어갈 때마다 손뼉을 치며 웃었어요. 몇 번이고 반복하면서 넣고 빼는 재미를 알아 가는 중이랍니다.
점심은 밥과 미역국을 거의 다 먹었고, 낮잠은 12시 20분부터 2시 10분까지 푹 잤어요. 기저귀는 세 번 갈았고 대변 한 번 보았습니다.
댁에서도 통에 장난감을 넣었다 빼는 놀이를 함께 해 보시면 무척 좋아할 거예요.

## 만 3세 (유아 — 새 학기 적응)
오늘 지호는 아침에 엄마와 헤어질 때 눈물이 났지만, 선생님 손을 잡고 교실에 들어와 좋아하는 기차 레일을 연결하며 금세 웃음을 되찾았어요. 옆 친구에게 "이거 같이 할래?" 하고 기차를 건네주기도 했답니다.
새로운 곳에 적응하는 데 시간이 필요한 시기라, 내일도 아침 인사를 짧고 밝게 해 주시면 지호가 더 편안하게 하루를 시작할 수 있을 것 같아요.

## 만 5세 (유아 — 놀이 속 배움)
오늘 하은이는 친구들과 "아이스크림 가게" 놀이를 하면서 직접 메뉴판을 만들었어요. "딸기는 3원, 초코는 5원" 하고 가격을 정하고, 손님이 오면 동전 모형을 세어 거스름돈을 주었답니다. 놀이 속에서 수를 세고 비교하는 경험을 즐겁게 하고 있어요.
댁에서 장보기를 할 때 하은이에게 물건 개수를 세어 보게 하시면 좋아할 것 같아요.
