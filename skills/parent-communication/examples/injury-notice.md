# 예시: 물림 사고 안내 — 전화 순서 + 문자 기록

> 가상 예시입니다. 원칙: **전화로 먼저 알리고**, 사실 → 즉시 조치 → 현재 상태 → 앞으로의 조치 → 유감 표현 → 연락처 순서로 전합니다. 다른 유아는 "친구"로만 말합니다.

## 상황 (교사 메모)
> 오후 3:10 쌓기 영역. 도윤(만 2세)이 친구와 같은 자동차를 잡다가 친구가 도윤 왼쪽 팔뚝을 물음. 잇자국 있고 살짝 붉음, 피는 안 남. 바로 흐르는 물에 씻기고 냉찜질 10분. 울다가 5분 뒤 진정, 이후 잘 놂.

## 1. 전화 (하원 전, 당일)
1. **인사와 용건**: "어머님, 새싹반 담임 OOO입니다. 오늘 도윤이가 놀이 중에 친구에게 팔을 물려서 먼저 전화로 알려드리려고 연락드렸습니다."
2. **사실**: "오후 3시 10분쯤 쌓기 영역에서 친구와 같은 자동차를 가지고 놀다가 왼쪽 팔뚝을 물렸습니다."
3. **조치와 상태**: "바로 흐르는 물에 씻기고 10분 정도 냉찜질을 했습니다. 잇자국이 있고 조금 붉지만 피는 나지 않았습니다. 5분 정도 울다가 진정해서 지금은 잘 놀고 있습니다."
4. **유감**: "제가 가까이에서 지켜보며 미리 막지 못해 죄송합니다."
5. **앞으로의 조치**: "하원 때 상처를 직접 보여드리겠습니다. 붉은 기가 심해지거나 붓고 열이 나면 진료를 받아 보시는 것이 좋겠습니다. 같은 자동차를 두고 다투는 일이 없도록 같은 놀잇감을 더 마련하고, 교사가 쌓기 영역 가까이에 머물겠습니다."
6. **경청**: 보호자의 질문과 감정에 먼저 공감한다. 상대 유아가 누구인지 물으시면 "친구 보호를 위해 말씀드리기 어려운 점 양해 부탁드립니다"라고 정중히 안내한다.

## 2. 문자/알림장 기록 (전화 후)
> 어머님, 앞서 전화로 말씀드린 내용을 정리해 드립니다.
> 오늘 오후 3시 10분경 놀이 중 친구에게 왼쪽 팔뚝을 물렸습니다. 곧바로 흐르는 물로 씻고 10분간 냉찜질을 했으며, 잇자국과 약간의 붉은 기는 있으나 출혈은 없었습니다. 이후 진정하여 즐겁게 놀이했습니다.
> 붉은 기가 심해지거나 붓고 열이 나면 진료를 권해 드리며, 진료가 필요하시면 어린이집으로도 알려 주세요.
> 미리 막지 못해 죄송합니다. 같은 일이 생기지 않도록 놀잇감을 넉넉히 준비하고 더 가까이에서 살피겠습니다.
> 궁금하신 점은 언제든 연락 주세요. (새싹반 담임 OOO / 어린이집 전화 000-0000-0000)

## 3. 기관 내부 처리
- 안전사고 기록부 작성 (시간, 장소, 상황, 조치, 보호자 연락 시각)
- 원장 보고
- 문 유아의 보호자에게도 **별도로** 사실을 알리고, 가정과 함께 지원할 방법을 이야기한다 (물린 유아의 정보는 알리지 않음)

## 쓰지 않는 표현
| ❌ | 이유 |
|---|---|
| "애들이 다 그럴 때예요" | 보호자 감정을 가볍게 여기는 말 |
| "OO이가 물었어요" | 다른 유아 정보 노출 |
| "별거 아니에요" / "괜찮을 거예요" | 상태를 단정함 |
| "제가 화장실 간 사이에…" | 변명처럼 들림 |
