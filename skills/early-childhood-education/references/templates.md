# 문서 양식 & 작성 예시

> 2019 개정 누리과정 이후 계획안 형식은 **기관 자율**이다. 아래는 기본 양식이며 사용자의 기관 양식이 있으면 그것을 우선하고 `user-notes.md`에 기록한다.

## 1. 주간 놀이 계획 및 실행 (놀이중심)

```
[반 이름 / 만 O세] 주간 놀이 계획 및 실행 (20OO. O. O ~ O. O)

■ 지난주 유아의 놀이 관심
- (관찰을 바탕으로 유아들이 몰입한 놀이 서술)

■ 예상되는 놀이 및 지원 계획
| 예상 놀이 | 놀이 지원 (공간·자료·상호작용·안전) | 관련 누리과정 영역/내용 |

■ 놀이 실행 기록 (사후 작성)
- 실제 일어난 놀이 흐름 (놀이 흐름도 / 웹 / 사진+설명)
- 유아의 배움 (누리과정 내용과 연결)
- 교사의 놀이 지원과 반성

■ 일상생활 / 안전교육 / 행사
■ 가정과의 연계
```

### 놀이 흐름 서술 예시 (만 5세)
> 바깥놀이터에서 개미를 발견한 유아들이 "개미 집은 어디야?" 하며 개미를 따라가기 시작했다. (자연탐구 - 생명체와 자연환경 소중히 여기기) 다음 날 유아들은 돋보기를 가져가 달라고 했고, 교사는 돋보기와 기록판을 준비해 주었다. (자료 지원) 개미를 그리던 지후가 "다리가 몇 개야?"라고 묻자 친구들과 함께 세어 보고 그림책에서 찾아보았다. (자연탐구 - 탐구과정 즐기기 / 의사소통 - 책과 이야기 즐기기)

## 4. 가정통신문
```
[OO유치원(어린이집) 가정통신문]                     20OO년 O월 O일

제목: ...

학부모님, 안녕하세요?
(계절 인사 1~2문장)

(본문: 무엇을 / 왜 / 언제 / 어떻게 / 가정에서 도와주실 일)

(마무리 인사)

OO유치원장 (어린이집 원장)
```
작성 팁: 쉬운 말 사용, 한 장 이내, 날짜·준비물은 **굵게** 또는 표로, 회신이 필요하면 절취선 아래 회신서를 붙인다. 다문화 가정이 있으면 쉬운 한국어 또는 번역 안내를 함께 고려한다.

## 5. 부모 상담 기록
```
상담일시 / 방법(대면·전화·온라인) / 유아명 / 상담자 / 참석자

1. 기관에서의 생활 (놀이, 또래관계, 일상생활) — 구체적 일화 중심
2. 가정에서의 모습 (부모님 이야기)
3. 부모님 질문·요청 사항
4. 함께 지원할 내용 (기관 / 가정)
5. 후속 조치
```
상담 화법: **강점 먼저 → 구체적 사실 → 함께 지원할 방법**. 비교·낙인 표현 금지. "~ 때문에 문제예요" 대신 "~하는 모습이 보여서 이렇게 도와주고 있어요".

## 6. 유아 관찰 종합 (학기말 / 발달 기록)
영역별로 2~4문장, 놀이 일화를 근거로 성장과 변화를 서술.
예) "사회관계: 학기 초에는 혼자 블록 놀이를 하는 시간이 많았으나, 요즘은 친구들과 '버스 만들기'를 하며 역할을 나누자고 먼저 제안하는 모습을 보입니다."
