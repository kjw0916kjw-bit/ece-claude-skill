# 2019 개정 누리과정 (만 3~5세)

- 고시: 교육부 고시 제2019-189호 / 보건복지부 고시 제2019-152호
- 시행: 2020년 3월
- 성격: 3~5세 유아를 위한 **국가 수준의 공통 교육과정** (유치원·어린이집 공통)
- 핵심 방향: **유아중심·놀이중심**, 교사 자율성 강화, 내용 간소화 (369개 → 59개 내용)
- 연령별 구분 없이 내용 제시 (3·4·5세 통합)

## 성격 (5가지)
가. 국가 수준의 공통성 추구
나. 지역, 기관 및 개인 수준의 다양성 추구
다. 유아의 전인적 발달과 행복 추구
라. 유아 중심과 놀이 중심 추구
마. 유아의 자율성과 창의성 신장 추구

## 추구하는 인간상
1. 건강한 사람
2. 자주적인 사람
3. 창의적인 사람
4. 감성이 풍부한 사람
5. 더불어 사는 사람

## 목적
유아가 놀이를 통해 심신의 건강과 조화로운 발달을 이루고 올바른 인성과 민주 시민의 자질의 기초를 형성하는 것.

## 목표
1. 자신의 소중함을 알고, 건강하고 안전한 생활 습관을 기른다.
2. 자신의 일을 스스로 해결하는 기초 능력을 기른다.
3. 호기심과 탐구심을 가지고 상상력과 창의력을 기른다.
4. 일상에서 아름다움을 느끼고 문화적 감수성을 기른다.
5. 사람과 자연을 존중하고 배려하며 소통하는 태도를 기른다.

## 5개 영역과 내용범주

| 영역 | 목표 요지 | 내용범주 |
|---|---|---|
| **신체운동·건강** | 실내외에서 신체활동을 즐기고, 건강하고 안전한 생활을 한다 | ① 신체활동 즐기기 ② 건강하게 생활하기 ③ 안전하게 생활하기 |
| **의사소통** | 일상생활에서 의사소통 능력과 상상력을 기른다 | ① 듣기와 말하기 ② 읽기와 쓰기에 관심 가지기 ③ 책과 이야기 즐기기 |
| **사회관계** | 자신을 존중하고 더불어 생활하는 태도를 가진다 | ① 나를 알고 존중하기 ② 더불어 생활하기 ③ 사회에 관심 가지기 |
| **예술경험** | 아름다움과 예술에 관심을 가지고 창의적 표현을 즐긴다 | ① 아름다움 찾아보기 ② 창의적으로 표현하기 ③ 예술 감상하기 |
| **자연탐구** | 탐구하는 과정을 즐기고, 자연과 더불어 사는 태도를 가진다 | ① 탐구과정 즐기기 ② 생활 속에서 탐구하기 ③ 자연과 더불어 살기 |

### 영역별 대표 내용 (요약·예시 — 원문 전체는 고시 원문 확인)
- **신체운동·건강**: 신체를 인식하고 움직인다 / 신체 움직임을 조절한다 / 기초적인 이동·제자리·도구 이용 움직임 / 실내외 신체활동에 자발적으로 참여 / 몸과 주변을 깨끗이 / 바른 식생활 / 휴식 / 질병 예방 / 안전한 놀이 / TV·컴퓨터·스마트폰 바르게 사용 / 교통안전 / 위험 상황 시 도움 요청
- **의사소통**: 말이나 이야기를 관심 있게 듣는다 / 경험·느낌·생각을 말한다 / 상황에 적절한 단어 사용 / 바른 태도로 듣고 말한다 / 고운 말 사용 / 말과 글의 관계 / 주변 상징·글자 읽기에 관심 / 자기 생각을 글자와 비슷한 형태로 표현 / 책에 관심 / 동화·동시의 말 재미 / 말놀이·이야기 짓기
- **사회관계**: 나를 알고 소중히 여긴다 / 감정을 알고 상황에 맞게 표현 / 스스로 할 수 있는 일을 한다 / 가족 / 친구와 협력 / 갈등 해결 / 다른 사람 감정 공감 / 약속·규칙 / 동네 / 우리나라 / 다양한 문화
- **예술경험**: 주변 환경·자연의 아름다움 / 예술적 요소 탐색 / 노래·리듬 / 신체·도구로 움직임과 춤 / 다양한 미술 재료 / 극놀이 / 다양한 예술 감상 / 전통 예술 감상
- **자연탐구**: 주변 세계에 호기심 / 궁금한 것 탐구 / 탐구과정 참여 / 물체·물질 특성 / 수량·셈 / 공간·도형 / 측정 / 규칙성 / 자료 분류·정리 / 도구·기계 / 생명체 소중히 / 날씨·계절 / 자연과 환경

## 운영 원칙 (편성·운영)
- 1일 **4~5시간**을 기준으로 편성 (확장 시간 연계 운영 가능)
- 일과 속에서 **유아가 충분히 놀이할 수 있도록** 편성
- 성별, 신체적 특성, 장애, 종교, 가족 및 문화적 배경 등에 따른 차별이 없도록
- 장애 등 특별한 요구가 있는 유아에 맞게 조정
- 가정·지역사회와 협력
- 교사 연수를 통해 개선

## 교수·학습
- 유아가 흥미와 관심에 따라 **놀이를 자유롭게 선택**하고 즐기도록
- 놀이를 통해 배우도록
- 실내외 환경을 활용
- 개별·소집단·대집단 활동 균형
- 5개 영역 내용이 **통합적으로** 경험되도록
- 개인차 고려

## 평가
- 누리과정 운영의 질 개선을 위해 **유아 평가와 운영 평가** 실시
- 유아의 특성·변화 정도, 운영 적절성 평가
- **기관 실정에 맞게 자율적으로** 방법 선정 (관찰, 기록, 작품 등)
- 결과는 유아 이해와 운영 개선, 부모 면담 자료로 활용
- 평가 자료로 서열화·비교 금지 취지

## 2019 개정의 주요 변화 (이전 2015/2012 누리과정 대비)
| 이전 | 2019 개정 |
|---|---|
| 연령별 세부내용 (369개) | 연령 구분 없이 59개 내용 |
| 생활주제 중심 연간·월간·주간·일일 계획 | 계획 형식 **자율** (놀이 흐름 중심, 사후 기록 가능) |
| 교사 주도 활동 | 유아 주도 놀이, 교사는 **놀이 지원자** |
| 10개 생활주제 예시 | 생활주제 강요하지 않음 |
| 평가 항목 제시 | 평가 방법 자율화 |
