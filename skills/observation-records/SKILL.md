# 관찰기록 작성·분석

`early-childhood-education` 스킬의 `references/observation-assessment.md`, `development.md`, `nuri-curriculum.md`를 기준으로 한다. `~/.claude/ece/user-notes.md`가 있으면 사용자 규칙을 우선 적용한다.

## 1. 메모 → 일화기록 변환 절차
1. 교사의 메모에서 **사실**(누가, 언제, 어디서, 무엇을 말하고 했는가)만 뽑는다.
2. 메모에 섞인 **판단·해석**은 따로 떼어 `[해석]` 칸으로 옮기고 "~로 보인다", "~인 것 같다"로 완화한다.
3. 유아의 말은 큰따옴표로 그대로 둔다. 없는 말을 지어내지 않는다.
4. 메모에 없는 사실은 추가하지 않는다. 빠진 정보(날짜, 장소 등)는 `( )` 빈칸으로 남기고 사용자에게 알려준다.
5. 관련 영역·내용범주를 1~3개 연결한다.
6. 다음 놀이 지원 계획을 1~3개 제안한다.

## 2. 판단 표현 → 행동 서술 바꾸기
| 피할 표현 | 바꿔 쓰기 예시 |
|---|---|
| 산만하다 | 10분 동안 블록, 미술, 역할놀이 영역을 옮겨 다녔다 |
| 공격적이다 | 친구가 가진 자동차를 잡아당기며 "내 거야!"라고 말했다 |
| 소극적이다 / 내성적이다 | 친구들의 놀이를 3분 정도 지켜본 뒤 혼자 퍼즐을 골랐다 |
| 착하다 | 넘어진 친구에게 다가가 "괜찮아?" 하고 물었다 |
| 고집이 세다 | 정리 시간에 "이거 다 만들고 할래"라고 말하며 블록을 계속 쌓았다 |
| 발달이 늦다 | (진단 표현 금지) 구체적 행동만 기록하고, 우려 시 부모 상담·전문가 연계 권고 |

## 3. 해석 쓰는 법
- 발달 특성(development.md)과 연결하되 "이 시기 유아에게 흔히 나타나는"처럼 일반화한다.
- 강점 관점: 무엇을 못 하는지보다 **무엇을 시도하고 있는지**를 쓴다.
- 한 번의 관찰로 결론 내리지 않는다: "지속적으로 관찰할 예정이다".

## 4. 학기말 종합 의견 (발달 기록)
- 영역별 2~4문장, 학기 초 → 현재의 **변화**를 일화 근거로 쓴다.
- 부모가 읽는 글이므로 전문 용어를 줄이고 따뜻하고 구체적으로 쓴다.
- 모든 유아에게 같은 문장을 돌려쓰지 않는다. 일화가 부족하면 사용자에게 더 받는다.
- 비교·서열 표현 금지("반에서 가장 ~").

## 5. 개인정보
- 기록 예시와 결과물에는 이니셜·가명을 쓰도록 권한다.
- 사용자가 실명을 넣어도 외부 서비스로 보내지 않는다.

관찰 해석이 복잡하거나 여러 건을 한꺼번에 분석해야 하면 `observation-analyst` 에이전트에 맡긴다.
