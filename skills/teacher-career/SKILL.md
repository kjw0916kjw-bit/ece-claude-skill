# 교사 진로 준비 (면접·임용·자기소개서)

이론은 `early-childhood-education` 스킬의 `references/theories.md`, `nuri-curriculum.md`, `policy.md`를 근거로 한다. 사용자의 경력·지원 기관 정보는 `~/.claude/ece/user-notes.md`에 있으면 활용한다.

## 1. 채용 면접 (어린이집·유치원)

### 자주 나오는 질문 유형
| 유형 | 예시 질문 |
|---|---|
| 지원 동기·교육관 | 왜 유아교사가 되고 싶은가요? / 본인의 교육관(보육관)은? / 우리 기관에 지원한 이유는? |
| 놀이중심 교육과정 | 놀이중심 교육과정을 어떻게 실천하겠습니까? / 교사의 놀이 지원이란? |
| 상황 대처 | 유아끼리 다툴 때 / 등원 거부·분리불안 / 편식 / 물림 사고 발생 시 |
| 학부모 소통 | 민원이 들어오면? / 다른 아이 때문에 다쳤다고 항의하면? |
| 안전·아동학대 | 아동학대 의심 정황을 발견하면? / 안전사고 예방 방법은? |
| 동료 관계 | 동료 교사와 의견이 다를 때? / 원장님 지시가 본인 생각과 다르면? |
| 자기 이해 | 장점과 단점 / 스트레스 관리 / 실습에서 기억에 남는 경험 |

### 답변 구성 원칙
- **결론 먼저 → 이유 → 구체적 경험/예시 → 기관에서의 실천 다짐** (1분 내외).
- 상황 질문은 **안전 확보 → 유아 정서 지원 → 사실 파악 → 보호자 연락 → 기록·보고 → 재발 방지** 순서.
- 아동학대 질문: **신고의무자로서 의심되면 112 신고**가 핵심. "원장님께 먼저 보고 후 판단" 식으로 신고를 미루는 답은 감점 요소임을 알려준다.
- 실습·경험 일화를 넣어 **나만의 답**이 되게 한다. 사용자의 경험을 먼저 물어본다.
- 지원 기관(예: 법인·직장어린이집·국공립)의 **설립 이념·특색**을 반영하라고 조언하되, 기관 정보는 지어내지 않고 사용자에게 확인하거나 공개 자료를 찾는다.

### 모의면접 진행
1. 기관 유형, 경력(신입/경력), 원하는 질문 수를 묻는다.
2. 질문을 **한 번에 하나씩** 낸다. 사용자가 답한 뒤에 피드백한다.
3. 피드백: 잘한 점 1~2개 → 보완할 점 1~2개 → 다듬은 모범 답안 예시.
4. 끝나면 전체 총평과 자주 보인 습관(예: 결론이 늦다)을 정리한다.

## 2. 공립 유치원 임용시험 [세부 사항은 해당 연도 공고 확인 필요]
- 1차: 교육학 + 유아교육 전공(서답형). 핵심은 **누리과정 원문 용어와 이론가 개념을 정확하게** 쓰는 것.
  - 서술 요령: 문항이 묻는 개수만큼 정확히 답한다, 개념어를 그대로 쓴다, 사례 문항은 사례 속 근거를 짚는다.
- 2차: 수업실연·심층면접 등 (시도별로 다름). 수업실연은 놀이중심 원칙(유아 관심에서 출발, 교사의 놀이 지원 발문)을 보여준다.
- 문제 출제 시 실제 기출을 지어내지 않는다. "기출 유형 예시"로만 제시한다.

## 3. 자기소개서
- 항목: 성장 과정 / 교육관 / 경험(실습·봉사) / 지원 동기 / 입사 후 포부.
- 추상어("열정", "사랑") 대신 **구체적 일화**로 보여준다.
- 사용자가 준 경험만 쓰고 경험을 지어내지 않는다. 부족하면 질문해서 끌어낸다.

## 4. 예시
- `examples/interview-answers.md`: 자주 나오는 질문 5개에 대한 모범 답변과 면접관이 보는 포인트

예시 속 경험은 가상의 것이다. 사용자의 답을 다듬을 때는 사용자 본인의 경험으로 바꾼다.

모의면접은 `interview-coach` 에이전트에 맡길 수 있다.
