# 놀이계획 작성

먼저 `early-childhood-education` 스킬의 핵심 원칙과 `references/templates.md`, `references/nuri-curriculum.md`(영아반이면 `standard-childcare.md`)를 따른다. 사용자 규칙은 `~/.claude/ece/user-notes.md`가 있으면 우선 적용한다.

## 1. 필요한 정보 (없으면 기본값을 쓰고 밝힌다)
| 항목 | 기본값 |
|---|---|
| 연령 | 만 4세 |
| 기간 | 주간 (5일) |
| 출발점 | 최근 관찰된 유아의 놀이 관심 — 없으면 계절·일상에서 자주 나타나는 관심을 "예상 놀이"로 제시 |
| 양식 | 사용자 기관 양식 → 없으면 templates.md 주간 놀이 계획 및 실행 |

## 2. 작성 원칙
- **출발은 유아의 관심**: "지난주 유아들은 ~에 관심을 보였다"로 시작한다. 교사가 정한 주제를 먼저 내세우지 않는다.
- **예상 놀이는 '예상'일 뿐**: 계획은 유연하며, 실제 놀이 흐름은 사후 기록으로 남긴다고 명시한다.
- **놀이 지원은 5가지로 구체화**: 공간 / 자료 / 시간 / 상호작용(개방형 질문 예시 포함) / 안전.
- **영역 연계는 자연스럽게**: 놀이 하나에 1~3개 영역·내용범주를 괄호로 연결한다. 억지로 5개 영역을 모두 채우지 않는다.
- **일상과 바깥놀이 포함**: 실내 놀이만 계획하지 않는다. 바깥놀이는 매일 포함하는 것을 기본으로 한다.
- **영아반**: 활동보다 일상(수유·낮잠·기저귀·손씻기)과 감각 탐색, 개별 일과를 중심으로 쓴다.

## 3. 놀이 흐름도 (웹) 작성
```
            [시작된 놀이 관심]
           /        |         \
   [확장 놀이 A] [확장 놀이 B] [확장 놀이 C]
       |              |
  (교사 지원)     (유아 제안)
```
- 각 가지에 **누가 제안했는지**(유아/교사)와 **어떤 지원**이 있었는지 짧게 붙인다.
- 텍스트 결과물에서는 들여쓰기 목록이나 표로 나타내도 된다.

## 4. 놀이 지원 아이디어 은행 (계절별로 자주 나타나는 관심 — 강요 금지, 참고용)
| 시기 | 자주 나타나는 관심 | 지원 자료 예시 |
|---|---|---|
| 3~4월 | 새 친구·새 교실, 봄꽃, 새싹 | 이름표 놀이, 돋보기, 씨앗·화분 |
| 5~6월 | 곤충, 가족, 비·물웅덩이 | 채집통, 우비, 물길 놀이 도구 |
| 7~8월 | 물놀이, 그림자, 더위 | 물총·스펀지, 손전등, 얼음 |
| 9~10월 | 낙엽·열매, 추석, 하늘 | 자연물, 송편 반죽 놀이, 바람개비 |
| 11~12월 | 겨울 준비, 동물 겨울나기, 크리스마스 | 천·담요, 상자 집, 반짝이 재료 |
| 1~2월 | 눈·얼음, 설날, 형님반 준비 | 얼음 실험, 전통놀이, 졸업·진급 기록 |

## 5. 마무리 점검
- [ ] 유아 관심에서 출발했는가?
- [ ] "시킨다/진행한다" 같은 교사 주도 표현이 없는가?
- [ ] 놀이 지원이 공간·자료·시간·상호작용·안전 중 구체적으로 적혔는가?
- [ ] 영역 연계가 정확한가? (영역명·내용범주 이름은 고시 그대로)
- [ ] 안전 고려 사항이 있는가?
- [ ] 유아 실명 대신 가명·이니셜을 썼는가?

문서 검토가 필요하면 `curriculum-reviewer` 에이전트에 맡긴다.
