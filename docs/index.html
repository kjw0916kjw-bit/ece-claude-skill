앱으로 설치하기

연습실을 열고 아래처럼 홈 화면에 추가하면 앱처럼 쓸 수 있어요. 한 번 연 뒤에는 인터넷이 끊겨도 열려요.

안드로이드

  1. 크롬 또는 삼성 인터넷으로 열기
  2. 메뉴(⋮ 또는 ≡) 누르기
  3. 앱 설치 또는 홈 화면에 추가

아이폰 · 아이패드

  1. 사파리로 열기
  2. 아래쪽 공유 버튼 누르기
  3. 홈 화면에 추가

PC

  1. 크롬 또는 엣지로 열기
  2. 주소창 오른쪽 설치 아이콘 누르기
  3. 설치 확인
