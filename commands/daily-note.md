# 알림장 작성

요청: $ARGUMENTS

1. `parent-communication` 스킬의 "알림장" 지침을 따른다.
2. 오늘의 구체적 일화가 없으면 무엇을 하며 놀았는지 묻는다. 일화를 지어내지 않는다.
3. 3~6문장: 놀이 일화(유아의 말 인용 가능) → 배움의 의미를 쉬운 말로 → 영아면 식사·낮잠·배변 → 가정 연계 한 줄.
4. 여러 유아를 한 번에 요청하면 유아마다 문장이 겹치지 않게 쓴다.
5. 다른 유아는 "친구"로만 표현한다.
