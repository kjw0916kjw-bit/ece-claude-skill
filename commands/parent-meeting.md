# 부모상담

요청: $ARGUMENTS

1. `parent-communication` 스킬의 "부모 상담" 지침과 `early-childhood-education` 스킬의 `references/templates.md` 상담 기록 양식을 따른다.
2. **준비**라면: 강점 중심 일화 3~5개 정리, 부모에게 물어볼 질문 5개, 함께 지원할 제안, 어려운 주제가 있다면 말하는 순서와 예시 문장.
3. **기록**이라면: 상담 메모를 양식에 맞춰 정리하고 후속 조치를 뽑는다.
4. 발달 우려가 있어도 진단하지 않는다. 필요하면 영유아건강검진·전문기관 안내 문장을 제안한다.
5. 일화가 부족하면 `observation-analyst` 에이전트로 관찰기록을 먼저 정리하자고 제안한다.
