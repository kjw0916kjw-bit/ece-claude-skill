# 유아교육 문서 검토

대상: $ARGUMENTS

1. 대상이 파일 경로면 읽는다 (docx/pdf/hwp는 텍스트로 변환이 필요하면 안내한다).
2. 문서 종류를 판단한다: 계획안 / 관찰기록 / 학부모 문서 / 기타.
3. `curriculum-reviewer` 에이전트로 교육과정·기록 관점 검토를 맡긴다.
4. 학부모 문서면 `parent-communicator`, 행사·바깥놀이·현장학습 등 안전 요소가 있으면 `safety-health-advisor`에도 맡긴다. 서로 관련 없는 검토는 동시에 실행한다.
5. 결과를 합쳐 "꼭 고칠 것 / 고치면 좋은 것"으로 정리하고, 원하면 고친 버전을 만들어 준다.
