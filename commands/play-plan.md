# 놀이계획안 작성

요청: $ARGUMENTS

1. `play-planning` 스킬을 로드하고 따른다.
2. 요청에서 연령·기간·유아의 놀이 관심을 찾는다. 놀이 관심이 없으면 최근에 유아들이 무엇에 관심을 보였는지 한 번만 묻고, 사용자가 모른다고 하면 계절에 맞는 예상 놀이로 작성한다.
3. 분량이 크거나(주간 계획) 여러 반이면 `play-planner` 에이전트에 맡긴다.
4. 작성 후 `curriculum-reviewer` 관점의 마무리 점검 결과를 붙인다.
5. 사용자가 원하면 파일로 저장한다 (`~/.claude/ece/user-notes.md`의 저장 위치 우선).
