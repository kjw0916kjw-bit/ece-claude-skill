# 가정통신문 작성

요청: $ARGUMENTS

1. `parent-communication` 스킬을 로드하고 따른다.
2. 주제, 날짜/시간, 장소, 준비물, 비용, 회신 필요 여부를 확인한다. 빠진 핵심 정보는 `[확인 필요]`로 표시하고 마지막에 목록으로 알려준다 (지어내지 않는다).
3. 사고·다툼·감염병처럼 민감한 내용이면 `parent-communicator` 에이전트에 맡기고, 안전·건강 판단이 필요하면 `safety-health-advisor`의 관점을 반영한다.
4. 한 장 이내의 완성본 + 필요하면 회신서를 준다.
5. 사용자가 원하면 파일(.md 또는 .docx)로 저장한다.
