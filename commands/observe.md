# 관찰기록 정리

관찰 메모: $ARGUMENTS

1. `observation-records` 스킬을 로드하고 따른다.
2. 메모가 파일 경로면 읽는다. 메모가 비어 있으면 관찰 내용을 붙여 달라고 요청한다.
3. 일화기록 양식(기본 정보 / 사실 / 해석 / 관련 영역 / 지원 계획)으로 정리한다.
4. 입력에 없는 사실은 지어내지 않고 `( )`로 비운 뒤 무엇이 빠졌는지 알려준다.
5. 여러 건이거나 학기말 종합 의견이 필요하면 `observation-analyst` 에이전트에 맡긴다.
6. 마지막에 고친 판단 표현 목록을 붙인다.
