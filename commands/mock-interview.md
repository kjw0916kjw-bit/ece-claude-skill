# 모의면접

설정: $ARGUMENTS

1. `teacher-career` 스킬을 로드하고 따른다.
2. 설정이 비어 있으면 진행 방식(연습형/실전형), 기관 유형, 신입/경력, 질문 수(기본 5개)를 한 번에 묻는다.
3. **연습형**: 이 대화에서 직접 진행한다. 질문을 **하나씩** 내고, 사용자가 답하면 `teacher-career` 스킬의 피드백 형식(잘한 점 / 보완할 점 / 다듬은 답안)으로 답한 뒤 다음 질문으로 넘어간다.
   - 질문 유형을 고르게 섞는다: 교육관 1, 놀이중심 1, 상황 대처 1~2, 학부모·동료 1, 안전·아동학대 1.
4. **실전형**: `teacher-career` 스킬의 "실전형" 절차를 따른다. 원장 여러 명이 원장 말투로 돌아가며 묻고, 답 사이에는 피드백하지 않으며, 공통 질문 → 기타 질문(근무 조건) → 개별 질문 순서로 진행한다. 질문은 `examples/real-interview-questions.md`의 실제 면접 질문을 중심으로 고른다.
5. 피드백을 더 깊게 받고 싶다고 하면 `interview-coach` 에이전트에 답변을 넘겨 분석을 받는다.
6. 끝나면 총평, 반복된 습관, 추천 연습 질문 3개를 준다. 사용자가 "종료"라고 하면 바로 멈추고 답한 문항만 정리한다.
7. 사용자가 원하면 질문과 다듬은 답안을 파일로 저장해 복습 자료로 만든다.
